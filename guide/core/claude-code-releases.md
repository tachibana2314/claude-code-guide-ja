## 2.1.xシリーズ（2026年1月〜3月）

### v2.1.77（2026-03-17）

- **新機能**: ⭐ Opus 4.6のデフォルト最大出力トークンが64kに引き上げ、Opus 4.6とSonnet 4.6の上限が128kトークンに引き上げ
- **新機能**: `allowRead` サンドボックスファイルシステム設定で `denyRead` リージョン内の読み取りアクセスを再許可
- **新機能**: `/copy N` でN番目に新しいアシスタントレスポンスを直接コピー
- **新機能**: `/branch` コマンド（`/fork` を置き換え; `/fork` はエイリアスとして引き続き機能）
- **新機能**: `SendMessage` が停止したエージェントをバックグラウンドでエラーを返す代わりに自動再開するようになった
- **修正**: ⚠️ **セキュリティ** — `PreToolUse` フックが `"allow"` を返すことで、エンタープライズ管理設定を含む `deny` パーミッションルールをバイパスできた問題
- **修正**: スラッシュコマンドオーバーレイが繰り返し開閉されてバイナリダウンロードが重複トリガーされた際に、自動アップデーターが数十GBのメモリを蓄積していた問題
- **修正**: `--resume` でメモリ抽出書き込みとメインのトランスクリプト間のレースにより最近の会話履歴が静かに切り捨てられていた問題
- **修正**: 複合bashコマンド（例: `cd src && npm test`）の「Always Allow」が、サブコマンドごとではなく文字列全体に対して単一ルールを保存し、無効なルールと繰り返しのパーミッションプロンプトを引き起こしていた問題
- **修正**: WriteツールがCRLFファイルを上書きするか、CRLFディレクトリにファイルを作成する際に改行コードを静かに変換していた問題
- **修正**: APIが非ストリーミングモードにフォールバックした際にコストとトークン使用量が追跡されなかった問題
- **修正**: `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` がベータのツールスキーマフィールドを削除せず、プロキシゲートウェイがリクエストを拒否していた問題
- **修正**: Bashツールがシステムの一時ディレクトリパスにスペースが含まれている場合、成功したコマンドに対してエラーを報告していた問題
- **修正**: ペースト直後に入力すると貼り付けた内容が失われる問題; `/feedback` でCtrl+Dが前方削除ではなく終了していた問題
- **修正**: 様々なレンダリング修正: 番号付きリストの数字、CJKの出血、tmuxでの背景色、VS Codeでのハイパーリンクが2度開く問題
- **修正**: リーダーが終了してもTeammateペインが閉じない問題; SSH経由のtmuxでiTerm2セッションがテキスト選択時にクラッシュする問題
- **破壊的変更**: `Agent` ツールが `resume` パラメーターを受け入れなくなった — `SendMessage({to: agentId})` を使用して以前に生成されたエージェントを継続する
- **VSCode**: カンマを含むgitignoreパターンが `@`-メンションファイルピッカーからファイルタイプを静かに除外していた問題を修正; スクロールホイールの応答性を改善; planプレビュータブのタイトルを改善
- **パフォーマンス**: キーチェーンのクレデンシャル読み取りをモジュールロードと並行して行うことでmacOSでの起動を高速化（〜60ms）; フォークが多いセッションでの `--resume` を高速化（最大45%高速、ピークメモリ100〜150MB削減）

### v2.1.76（2026-03-14）

- **新機能**: ⭐ MCPエリシテーションのサポート — MCPサーバーがインタラクティブなダイアログ（フォームフィールドまたはブラウザURL）経由でタスク中に構造化された入力をリクエストできるようになった
- **新機能**: `Elicitation` と `ElicitationResult` フックでMCP入力レスポンスをサーバーに送り返す前にインターセプトして上書きできる
- **新機能**: コンパクション完了後に発火する `PostCompact` フック
- **新機能**: 起動時にセッションの表示名を設定する `-n` / `--name <name>` CLIフラグ
- **新機能**: 大規模なモノリポでの `claude --worktree` 向け `worktree.sparsePaths` 設定 — git sparse-checkoutで必要なディレクトリのみをチェックアウト
- **新機能**: モデルの努力レベルを設定する `/effort` スラッシュコマンド
- **修正**: 会話コンパクション後に遅延ツール（`ToolSearch` 経由で読み込まれる）の入力スキーマが失われ — 配列と数値パラメーターが型エラーで拒否されていた問題
- **修正**: 連続した失敗後に自動コンパクションが無限にリトライしていた — サーキットブレーカーが3回の試みで停止するようになった
- **修正**: 引用符付き引数に `#` が含まれている場合に `Bash(cmd:*)` パーミッションルールが一致しなかった問題
- **修正**: スラッシュコマンドが「Unknown skill」を表示していた問題
- **修正**: planモードがすでに承認されたプランの後に再承認を求めていた問題
- **修正**: パーミッションダイアログやプランエディターが開いている間、音声モードがキープレスを飲み込んでいた問題
- **修正**: npmからインストールした場合、Windowsで `/voice` が機能しなかった問題
- **修正**: WebSocket接続が長時間切断した後にブリッジセッションが回復できなかった問題
- **改善**: gitの参照を直接読み取り、冗長な `git fetch` をスキップすることで `--worktree` 起動パフォーマンスを改善
- **改善**: バックグラウンドエージェントを終了しても会話コンテキストに部分的な結果を保持するようになった
- **改善**: モデルフォールバック通知 — 人間が読めるモデル名で常に表示されるようになった
- **改善**: 古いworktreeのクリーンアップ — 並行実行が中断された後に残ったworktreeが自動的にクリーンアップされるようになった
- **改善**: ダークターミナルテーマでの引用ブロックの可読性 — 暗いスタイルではなく左バー付きイタリック
- **更新**: `--plugin-dir` は1つのパスのみを受け入れるようになった; 複数のディレクトリには繰り返しフラグを使用
- **VSCode**: カンマを含むgitignoreパターンが `@`-メンションファイルピッカーからファイルタイプ全体を静かに除外していた問題を修正

- **修正**: Bashツールがパイプコマンドで `!` をエスケープする問題（例: `jq 'select(.x != .y)'` が正しく動作するようになった）

- **修正**: 破損したマーケットプレイス設定パスの処理
- **修正**: フォークされたまたは継続されたセッションを再開後に `/resume` がセッション名を失っていた問題
- **改善**: macOSの非MDMマシンでの起動パフォーマンス（不要なサブプロセス生成をスキップ）
- **改善**: 非同期フック完了メッセージがデフォルトで非表示になった（`--verbose` またはトランスクリプトモードで表示）
